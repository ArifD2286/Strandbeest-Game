# Strandbeest Game

A game where you are a cloud trying to get Strandbeests across the beach by "shooting" wind charges at them. Try to get the best time possible and make sure to not send too much wind as the Strandbeests could fall!

### How to play:
- To complete the game, all you have to do is just get all upgrades.
- Every time you get the Strandbeest to cross the line before x seconds (will decide time later), you will earn 50 pipes, if you get any later than that you will earn only 25 pipes.
- There will be a bar next to the Strandbeest to show its speed, go too fast and it would fall over :< but there would also be walking momentum.


### Controls:
- Press [SPACE] to shoot wind charges
- Get upgrades on the upgrade panel:
  - Upgrade the Strandbeest's speed tolerance
  - Upgrade the Strandbeest's walking momentum
