# Strandbeest Game


![Alt Text](https://github.com/ArifD2286/Strandbeest-Game/blob/main/strandbeest-game/assets/game%20cover.png)


A game where you are a cloud trying to get Strandbeests across the beach by "shooting" wind charges at them. Try to get the best time possible and make sure to not send too much wind as the Strandbeests could break!


### How to play:
- Obtain all upgrades available to officially complete the game.
- Every time you get the Strandbeest to cross the line before 45 seconds, you will earn 50 pipes, if you get any later than that you will earn only 25 pipes.
- When making the Strandbeest walk, make sure to not let it go too fast as it could break. You can increase the speed tolerance for the Strandbeest by upgrading it.


### Controls:
- Press [SPACE] to shoot wind charges
- Get upgrades on the upgrade panel:
  - Upgrade the Strandbeest's speed tolerance
  - Upgrade the Strandbeest's walking momentum


### Made using:
- Godot and coded using its native language (gdscript)
